# customer-healthcare-data-analysis
SQL project for analyzing customer and healthcare data
# Customer Healthcare Data Analysis

## Описание проекта

SQL-проект по анализу клиентских и медицинских данных.

## Инструменты

- SQL

## Задачи проекта

- Объединение данных пациентов, регионов и услуг
- Анализ количества оказанных услуг
- Анализ данных по полу и возрасту
- Работа с датами
- Поиск совпадений между таблицами
- Поиск дубликатов
- Расчет возраста пользователей
- Фильтрация данных по возрастным группам

## Использованные SQL-инструменты

- JOIN
- CASE
- GROUP BY
- COUNT
- Агрегатные функции
- Работа с датами
- Поиск дубликатов
- Фильтрация данных

## Результат

Проект демонстрирует работу с несколькими связанными таблицами, проверку качества данных и использование SQL для аналитических задач.
